Para ejecutar VSL1-1 en general:
- Descargar y descomprimir vsl-1.1-linux.zip
- Instalar jdk de Java (sino dispone de una versión instalada en el ordenador)
- Ejecutable: Debe abrir terminal en la carpeta donde se ha descomprimido VSL y escribir:
> java -jar vsl-1.1/vsl-app-1.1-linux.jar

Para ejecutar VSL1-1 en Windows (VSL original):
- Descargar en la misma carpeta: 
* VSL: vsl-1.1.zip
* JDK-Java: jdk-11.0.28_windows-x64_bin.zip (Windows-x64)
* Ejecutable: vsl_Windows_x64.bat.zip 
- Descomprimir lo descargado en la misma carpeta.
- Ejecutar vsl_Windows_x64.bat

Para ejecutar VSL1-1 en Linux  (VSL modificado):
- Descargar en la misma carpeta: 
* VSL: vsl-1.1-linux.zip
* JDK-Java: jdk-11.0.28_linux-x64_bin.tar.gz (Linux-x64, para Linux-arm64 debe descargar jdk compatible)
* Ejecutable: vsl_Linux_x64.sh.zip
- Descomprimir lo descargado en la misma carpeta.
- Ejecutar vsl_Linux_x64.sh

Para ejecutar VSL1-1 en MAC (VSL modificado):
- Descargar y descomprimir vsl-1.1-linux.zip (es compatible con Mac)
- Instalar jdk de Java (sino dispone de una versión instalada en el ordenador)
- Ejecutable: Debe abrir terminal en la carpeta donde se ha descomprimido VSL y escribir:
> java -jar vsl-1.1/vsl-app-1.1-linux.jar
